JSON (JavaScript Object Notation)

El estándar universal liviano para el intercambio de datos estructurados

¿Qué es JSON y por qué es el estándar web?

JSON es un formato de texto independiente del lenguaje utilizado para transmitir y estructurar datos entre clientes (navegadores) y servidores web o APIs RESTful. Es más liviano y fácil de leer para humanos que XML.

Estructura Básica de Datos

JSON admite tipos de datos primarios: String (siempre entre comillas dobles), Number, Boolean, null, Array [] y Object {}.

// Objeto Literal en JavaScript 
const comision = {
    id: 101,
    modo: "Cyber Glow",
    activo: true,
    precio: 85
};
// Formato Formateado JSON (String) 
{
    "id": 101,
    "modo": "Cyber Glow",
    "activo": true,
    "precio": 85
}

Comunicación Cliente-Servidor: En JavaScript se utiliza JSON.stringify() para convertir objetos JS en cadenas JSON al enviar datos, y JSON.parse() para reconvertir cadenas JSON recibidas en objetos manipulables.
