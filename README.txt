# CYBER ART COMMISSIONS — estructura separada

- `index.html` — Página de Inicio / Identidad de Producto + modos y cotizador.
- `javascript.html` — Investigación de JavaScript Vanilla.
- `jquery.html` — Investigación de jQuery.
- `json.html` — Investigación de JSON.
- `hosting.html` — Investigación de Web Hosting y Dominios.
- `cuestionario.html` — Cuestionario interactivo de repaso (8 preguntas).
- `css/style.css` — Estilos Synthwave/Cyberpunk compartidos.
- `js/main.js` — JavaScript compartido: navegación, SFX, cotizador, demos, DNS, JSON y cuestionario.

Todas las páginas usan rutas relativas para `css/style.css` y `js/main.js`.
